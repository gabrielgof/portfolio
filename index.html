Cyphernode — Suporte Técnico On-Site

Site de serviços de suporte técnico em São Paulo — manutenção de computadores, reparos, upgrades, CCTV, smart home, redes, desenvolvimento web e automação. Construído do zero com HTML/CSS/JS, conectado ao Cloudflare Pages para deploy automático via GitHub. O site serve como vitrine para clientes corporativos e pessoas físicas, integrando conhecimento técnico com presença digital profissional.

HTML CSS JavaScript Cloudflare Pages GitHub
● Em produção 2024 — presente

Cyphernode Network Monitor

Ferramenta de monitoramento de infraestrutura de rede em Python puro (sem dependências externas). Verifica disponibilidade de hosts via ICMP, portas TCP e endpoints HTTP/HTTPS, gerando relatórios em texto ou JSON. Inclui CLI com argparser, testes unitários (TDD), configuração via JSON e códigos de saída para integração com cron/systemd. Parte do portfólio de Gabriel Gof.

Python Sockets HTTP CLI TDD
● Em produção 2025 — presente
